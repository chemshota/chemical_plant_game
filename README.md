# 化学プラント経営ゲーム

19〜20世紀の化学工業史をたどる、ターン制の工場レイアウト型経営ゲームです。敷地に装置を置き、配管でつなぎ、副生成物の行き先まで含めてプラントを設計します。ソーダ工業時代から電解工業時代、アンモニア工業時代へと会社を育てていきます。

## 起動方法

Node.js 18 以上が必要です。

```bash
npm install
npm run dev      # http://localhost:5173/ を開く
```

配布用にビルドする場合は `npm run build` を実行し、`dist/` を静的サーバーで配信します。

```bash
npm run build
npx vite preview
```

## 遊び方

1期は1か月です。装置の配置や契約の受注を済ませて「次の期へ」を押すと、生産・輸送・販売・決算がまとめて進みます。進行は毎期ブラウザに自動保存され、メニューからファイルへの書き出し・読み込みもできます。

### 敷地と配管

- 左のパネルで装置を選び、敷地のタイルに置きます (R で回転)。
- 配管は **物質ごと** に敷きます。同じ物質の配管はつながって1つの配管網になり、隣接する装置がその物質を出し入れします。装置どうしを直接くっつけてもつながりません。
- 別の物質の配管は同じタイルを通せません。交差させるには「パイプラック」の研究が必要です。
- **受入設備** が原料を市場価格で買い入れ、**出荷設備** が製品を倉庫へ送ります。どちらも敷地の外周に置きます。

### 詰まりと副生成物

装置は **出力の行き先がないと止まります**。たとえば芒硝炉は芒硝と一緒に塩化水素ガスを出すので、ガスの行き先を作らないと芒硝も作れません。行き先は次のどれかです。

- 出荷して売る
- 次の反応の原料にする (塩酸吸収塔で塩酸に、さらし粉工場でさらし粉に)
- 煙突 (気体) や廃棄場 (固体・液体) に捨てる

捨てると汚染度が上がり、許容値を超えた分に毎期罰金がかかります。規制は時代とともに厳しくなります。

配管網のなかでは、反応装置 → 貯槽 → 出荷 → 放出・投棄 の順に優先して配られます。余った分だけが売られ、さらに余った分が捨てられます。

### 経営

- **スポット市場**: 倉庫の製品は自動で売れますが、売るほど単価が下がります。1期に市場規模ぶん売ると平均単価は相場の 2/3 になります。
- **契約**: 相場より高い固定単価で、決まった量を決まった期間納めます。納入できないと違約金と信用低下、完遂すると信用が上がり、より大口の引き合いが来ます。
- **固定費**: 装置の維持費、地代、借入の利息が毎期かかります。期末の資金マイナスが3期続くと破産です。
- **研究**: 研究所が毎期生む研究ポイントで技術を取ります。新しい製法、既存製法の改良、物流や販売の改善から選びます。
- **イベント**: 原料高騰、需要急増、不況、設備事故のほか、アルカリ法の施行など史実に沿った規制が起こります。

### 時代

各時代の目標 (累計販売量・信用・企業価値) をすべて満たすと次の時代へ進みます。時代が変わると相場と規制が変わり、古い製法は採算が悪くなります。

| 時代 | 主な製法 | 設計上の課題 |
|---|---|---|
| ソーダ工業時代 | 鉛室法、ルブラン法 (芒硝炉 → 黒灰炉)、塩酸吸収塔、さらし粉、硫黄回収 | 塩化水素ガスと硫化カルシウム残渣の処理 |
| 電解工業時代 | 接触法、ソルベー法、発電所、電解槽、塩酸合成、塩素式さらし粉 | 苛性ソーダ・塩素・水素の連産バランスと電力 |
| アンモニア工業時代 | 水性ガス炉、アンモニア合成塔、硝酸、硫安、硝安 | 水素の調達と長い製品連鎖 |

第3時代の目標を達成するとキャンペーン達成です。

## 開発

```bash
npm test           # シミュレーションの単体テストと通しプレイ
npm run typecheck  # 型検査
```

```
index.html
src/
  main.ts
  data/   物質・装置と製法・技術・時代・イベントの定義
  sim/    ゲームロジック (DOM に依存しない)
  ui/     Canvas 描画、操作、パネル
tests/    Vitest
```

装置や製法、技術、時代の追加は `src/data/` の定義を足すところから始めます。開発上の約束ごとは `AGENT.md` にまとめています。
