# 化学プラント経営ゲーム

19〜20世紀の化学工業をモチーフにした、ターン制の経営シミュレーションゲームです。プレイヤーは化学プラントを建設・運営し、原料を仕入れて化学製品を生産・販売しながら、新しい製造プロセスを研究開発して時代の変遷に対応していきます。

ブラウザだけで動く素のHTML/CSS/JavaScriptで実装されており、ビルドや依存パッケージのインストールは不要です。

## 起動方法

ローカルにクローンして `index.html` をブラウザで開くだけで遊べます。

```bash
# そのまま開く
xdg-open index.html        # Linux
open index.html            # macOS

# あるいは簡易HTTPサーバーで
python3 -m http.server 8000
# → http://localhost:8000/ にアクセス
```

## ゲームの流れ

1. **プラントを建設する** — 利用可能な製造プロセスを選び、工場を建てます。
2. **原料を仕入れる** — 市場タブから食塩・石灰石・硫黄・石炭などを購入。
3. **ターンを終了する** — プラントが稼働して原料が製品に変換され、需要に応じて自動販売されます。
4. **研究開発に投資する** — 技術レベルを上げて新プロセスを解禁し、工程改善で利益率を高めます。
5. **時代の変化に対応する** — 技術の進歩に伴い時代が進み、製品ごとの需要バランスが変化します。

ヘッダーには常に **資金 / 期 / 時代 / 技術Lv** が表示され、画面下部の「ターン終了 ▶」で1期進行します。

### 製品
| ID | 名称 | 基準価格 |
|---|---|---|
| sulfuric_acid | 硫酸 | ¥650 |

市場価格はターンごとに ±15% 程度ランダムに変動し、基準価格への回帰傾向を持ちます (下限 ×0.5 / 上限 ×2.0)。

## 製造プロセス

| プロセス | 反応 | 必要技術Lv | 建設費 |
|---|---|:-:|---:|
| **接触法** | 硫黄 + 石炭 → 硫酸×2 | 1 | ¥4,000 |
| **ルブラン法** | 食塩×2 + 硫酸 → ソーダ灰 + 塩酸 | 1 | ¥6,000 |
| **ソルベー法** | 食塩×2 + 石灰石 → ソーダ灰×2 | 2 | ¥16,000 |
| **電解法** | 食塩×2 + 石炭×2 → 苛性ソーダ×2 + 塩素 | 3 | ¥38,000 |

ルブラン法は塩酸の供給源として、ソルベー法は効率的なソーダ灰生産として、電解法は苛性ソーダ・塩素を同時に得る高度プロセスとして、それぞれ異なる戦略的価値を持ちます。

## 時代と需要

| 時代 | 高需要の製品 |
|---|---|
| **ソーダ工業時代** | ソーダ灰・硫酸が中心 |
| **電解工業時代** | 苛性ソーダ・塩素の需要が拡大 |

需要は **極低 / 低 / 中 / 高 / 極高** の5段階で表示され、各レベルごとに1ターンに販売できる量の上限が決まります。時代が進むと需要構造が変化するため、生産ラインの組み替えが必要になります。

## 研究開発

研究タブから技術レベルアップと **工程改善研究** の両方に資金を投じることができます。

### 技術レベル
| Lv | 必要研究費 | 解禁内容 |
|:-:|---:|---|
| 2 | ¥12,000 | ソルベー法 |
| 3 | ¥30,000 | 電解法 (時代が「電解工業時代」へ) |
| 4 | ¥80,000 | — |

### 工程改善研究
| カテゴリ | 効果の例 |
|---|---|
| **原料調達技術** | 原料購入価格 -10% / -20% / -30% |
| **反応工程技術** | 全プロセスの運転費 -15% / -30% / -45% |
| **分離・精製技術** | ソルベー法・接触法の収率向上 |
| **電気化学技術** | 電解法専用の運転費削減・原料消費削減 (技術Lv3以降) |

## 画面構成

- **プラントタブ** — 建設済みプラントの一覧と新規建設、稼働状況の確認。
- **市場タブ** — 各化学物質の現在価格・前ターン比、原料の購入と自動購入設定。
- **在庫タブ** — 保有原料と製品の数量。
- **研究開発タブ** — 技術レベルアップと工程改善研究への投資。

下部のログには、ターンごとの生産量・販売量・収支などが出力されます。

## ファイル構成

```
chemical_plant_game/
├── index.html          # エントリポイント
├── css/
│   └── style.css       # 全UIのスタイル
└── js/
    ├── data.js         # 化学物質・プロセス・時代・研究データ定義
    ├── simulation.js   # ゲームロジック (市場・生産・販売・研究)
    ├── ui.js           # 各タブのレンダリングとイベント処理
    └── main.js         # 初期化とエントリ
```

新しい化学物質や製造プロセス、研究カテゴリを追加したい場合は、まず `js/data.js` の各定義オブジェクトに項目を追加し、必要に応じて `js/simulation.js` のシミュレーションロジックと `js/ui.js` の描画処理を更新します。
